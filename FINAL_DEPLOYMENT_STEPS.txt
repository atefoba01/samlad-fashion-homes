TROUBLESHOOTING

Problem: npm install fails
Solution: 
  - Make sure Node.js v18+ is installed: node --version
  - Try: npm install --legacy-peer-deps

Problem: npm run dev doesn't work
Solution:
  - Check .env file exists and has correct credentials
  - Make sure port 5173 is not in use
  - Try closing other terminals and trying again

Problem: Vercel deployment fails
Solution:
  - Check environment variables are added to Vercel dashboard
  - Make sure .env file is NOT committed to GitHub
  - Check build logs in Vercel for specific errors

Problem: WhatsApp links don't work
Solution:
  - They should be formatted as: https://wa.me/2348142805347
  - Test on mobile if possible
  - Verify the number 08142805347 is correct

Problem: Can't push to GitHub
Solution:
  - Double-check your token is correct
  - Make sure you're in the right folder
  - Try: git remote -v (to verify remote is correct)
